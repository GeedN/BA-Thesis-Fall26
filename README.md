This repository contains the following code and data files:
#### Data
- "data/raw_data_10-Nov-26_19-14.csv" : raw data
- "data/clean_field_data_10-Nov-26_19-14.csv" : data with more informative field names
- "data/cleaned_filtered_scored_data_10-Nov-26_19-14.csv" : data after cleaning and score calculation
#### Data Cleaning and Analysis
- "analysis.R" : Descriptive statistics, MANOVA, ANOVA, and relevant assumption testing
- "process_data.py" : Data cleaning and percentage score calculation for the SES, PANAS, and TPS-HRI
#### NAO Video Animation
- "animate.py" : Lining up gestures and script for NAO
- "gestures.py" : Defining gestures for NAO
